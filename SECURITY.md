# Security

Please report security problems privately through GitHub: the repository's **Security** tab →
**Report a vulnerability** (a private advisory only the maintainer sees). Do not open a public issue
for them.

The only official source of Grimcold is this repository and its Releases. Copies anywhere
else (videos, chat messages, "premium" versions, password-protected archives, anything that asks you
to turn off your antivirus) are not from this project: please report them as impersonation from the
copy's page.
